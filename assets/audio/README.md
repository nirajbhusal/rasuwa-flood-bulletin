# Mangal Dhun

Dashain background music is the YouTube video configured in `data/festival.json` as `bgm` (`provider: youtube`, `id`). The page embeds it with the privacy-enhanced IFrame API on `youtube-nocookie.com` only after the listener taps the play button. Nothing from YouTube is requested before that tap, and the page never autoplays.

Do not download or add a ripped audio file here. A local `mangal-dhun.mp3` is not used.
